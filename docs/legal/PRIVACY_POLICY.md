# Velnox — Privacy Policy
Legal version 1.1.0 · Effective 2026-08-24 · Updated 2026-08-24

Velnox does not require an account. When Save History is enabled, saved test history is stored in browser LocalStorage on the current device/browser profile. Clearing history removes that local Velnox history.

A network speed test necessarily sends test traffic to Cloudflare speed-test endpoints. Velnox may use Cloudflare-provided network metadata or browser locale to estimate the network-exit country for benchmark selection. Velnox does not place a raw IP address into local test history.

Country and Worldwide benchmark files are aggregated Cloudflare Radar datasets generated by the Velnox benchmark workflow, not personal user histories. Ko-fi, PromptPay support assets, GitHub Pages and email applications are third-party services with their own practices.

Share Result cards are generated locally in the user's browser from the selected result. Velnox does not upload a generated share card to a Benedict Interactive server. The card does not include raw IP addresses, saved history, or precise location. Country / Worldwide standing and exact metrics are included only when the user chooses those share options. If the user invokes the device share sheet or downloads the image, the receiving app or browser handles that file under its own practices.

Velnox V1.9 contains no advertising system, cross-site behavioural advertising tracker, or system for selling user data.
